# ARCA · Futurable

Agencia de Reubicación de Capacidades Humanas — experiencia interactiva de diseño ficción de Futurable para Tech Week Yucatán y futurable.work/arca.

- `arca/index.html` — la experiencia completa (18 preguntas, puntaje, pase de abordaje, QR).
- `arca/?estacion` — modo kiosco para la estación del evento (QR y reinicio por inactividad).
- `__forms.html` — esqueletos de Netlify Forms (`arca-respuestas`, `arca-correo`).
- `netlify.toml` — publica la raíz; `/` redirige a `/arca/`.

Esta rama se despliega en Netlify (proyecto arca-futurable). No requiere build.
